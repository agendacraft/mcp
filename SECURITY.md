# Security

Maintainer: the captain.

## Supported versions

The latest 0.x release receives security fixes. No standalone release has been published yet.

## Private reporting

Report vulnerabilities privately to [security@agendacraft.ai](mailto:security@agendacraft.ai).
Do not open a public issue for a vulnerability.

Include the affected version, MCP host, required scopes, expected/observed behavior, and a minimal
synthetic reproduction. Redact access/refresh tokens, introspection credentials, token files,
profile emails, task data, and sensitive request URLs. Do not attach production account exports.

The maintainer coordinates fixes and disclosure with the reporter. Response-time expectations
will be documented by the maintainer. Please allow time for a fix and
release before disclosing details publicly.
